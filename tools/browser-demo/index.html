Memory and output

One model tile is processed at a time. Finished pixels are encoded in strips, with bounded preview size and backpressure. No full-size float output is assembled.

Inference WASM memory is capped at 256 MiB per memory, tracked GPU buffers at 256 MiB, and each codec module at 128 MiB. Browser decoding, graphics-driver overhead and the browser itself are outside those caps.

PNG output streams into browser-local storage where supported. The fallback keeps at most 128 MiB of encoded data. Download your finished result for a durable copy. Transparency is composited on white; output is 8-bit sRGB.
